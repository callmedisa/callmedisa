### 🧭 How I work

- **Tests over trust.** A green test suite only checks what its author thought of, so I break the code on purpose to make sure the tests notice.
- **The database is the last line of defence.** Constraints, transactions and locks — not just validation in the API.
- **AI writes, I decide and verify.** I use AI to move fast, and I read every diff, run it, and probe the edge cases myself.
